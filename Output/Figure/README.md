# Figures

Publication figures generated by code under `Analysis_code/` belong here. PDF is the canonical publication format; PNG copies are retained for quick inspection where available.

The existing files document the accepted abstract and current full report. The LaTeX sources in `Output/overleaf/` reference this directory directly, so duplicate figure copies are unnecessary.

The four full-report figures `f1_observable.pdf` through
`f4_collapse_harmonics.pdf` can be rebuilt from the frozen historical tables with:

```bash
MPLCONFIGDIR=/tmp/netmob_mpl_cache /Users/pirin/miniconda3/bin/python \
  Archive/legacy_pipeline/full_report_refactor/code/pipelines/figures.py
```

The script reads only `Archive/legacy_pipeline/full_report_refactor/outputs/` and
writes the four PDFs here. It was successfully rerun after the project reorganization.
